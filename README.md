# We-Connect Personalized Webpage

## Project Description

We-Connect Personalized Webpage is an interactive web application built using HTML, CSS, and JavaScript. The project allows users to enter their personal information and receive a customized experience through greetings, age calculations and motivational quotes.

The application also uses localStorage to save user information even after the page is refreshed.

---

## Features

- User input form for name and age/date of birth
- Personalized greeting using template literals
- Age calculation in months
- Motivational quotes displayed using loops
- Data persistence using localStorage
- Responsive and visually appealing UI
